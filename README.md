# Python Web Scrapers & Automation Bots

A collection of custom Python scripts for web scraping, automated data processing, and system monitoring.

## 🛠️ Project Overview
* **`scraper.py`**: Extracts targeted data from web pages using BeautifulSoup / requests.
* **`organizer.py`**: Processes, cleans, and structures raw scraped data.
* **`monitor.py`**: Tracks execution status and outputs system logs.
* **`scraped_quotes.csv`**: Sample structured output file.
* **`status_log.json`**: Structured execution logs.
